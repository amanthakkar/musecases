Muse gadget skills I've written, dogfooded on my own hardware, and contributed to Meta's muse-gadget-sdk catalog. Filed 16 Oct 2026, these were the first community skill PRs in the upstream queue — a second contributor joined on 19 Oct (#251). Open, CLA signed, awaiting review. Two more skills — Home Assistant gateways and Jellyfin media servers — are drafted here in the lab (below). Tap a skill for the full picture.

Design principles

Read-only by default
Writes and commands are gated, explicit, and reversible where possible.
Guided setup, not guessing
Missing a layer? The skill walks you through that layer's setup instead of hallucinating a path.
Honest limits up front
Closed ecosystems say so in the skill — trades are stated before the user decides.
Real hardware only
If it isn't true on my own stack, it isn't in the skill.
